# Cybersecurity Tools - C++ Portfolio

A collection of defensive and offensive security tools built in C++ to understand how attacks work and how to defend against them.

## Tools

### 1. Password Strength Auditor - `password-auditor.cpp`
A defensive tool that audits password strength to protect users from brute-force attacks.
- Checks password length, numbers, uppercase, lowercase, symbols
- Calculates strength score
- Educates users on creating strong passwords
