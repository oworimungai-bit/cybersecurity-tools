# Password Strength Auditor - Cybersecurity Tool 1
A defensive security tool that audits password strength to protect users from brute-force attacks.

## What it does
- Checks password length, numbers, uppercase, lowercase, symbols
- Calculates strength score  
- Educates users on creating strong passwords

## Why this matters
Weak passwords are the #1 way accounts get hacked. This tool helps prevent that.

## How to run
g++ password-auditor.cpp -o auditor
./auditor
